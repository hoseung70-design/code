# 15초 금연 공익광고 자동 제작

외부 영상 서비스 없이, 내 Windows PC에서 **더블클릭 한 번으로** 15초 세로형 금연 공익광고를 만듭니다.

| 항목 | 규격 |
|---|---|
| 길이 | 정확히 15.000초 (450프레임) |
| 화면 | 1080 × 1920 (세로 9:16), 30fps |
| 파일 | MP4 (H.264 영상 + AAC 음향) |
| 자막 | 한글 (맑은 고딕 자동 사용) |
| 결과 | `output/smoking_campaign_15s.mp4` |

---

## 1. 처음 한 번만: 준비하기

필요한 프로그램은 **Python**과 **FFmpeg** 두 가지입니다.

### 1-1. 이미 설치되어 있는지 확인

1. 키보드에서 `윈도우 키`를 누르고 `cmd`를 입력한 뒤 **명령 프롬프트**를 엽니다.
2. 아래 명령을 한 줄씩 입력하고 Enter를 누릅니다.

```
py --version
ffmpeg -version
```

- `Python 3.12.x`처럼 **버전 번호가 나오면** 설치된 것입니다.
- `'py'은(는) ... 인식되지 않습니다`처럼 나오면 아래 순서대로 설치하세요.

### 1-2. Python 설치 (없을 때만)

1. https://www.python.org/downloads/ 에 접속해 노란색 **Download Python** 버튼을 누릅니다.
2. 내려받은 파일을 실행합니다.
3. **첫 화면 아래쪽의 `Add python.exe to PATH`를 꼭 체크**한 뒤 **Install Now**를 누릅니다.
4. 설치가 끝나면 명령 프롬프트를 **닫았다가 새로 열고** `py --version`으로 다시 확인합니다.

### 1-3. FFmpeg 설치 (없을 때만)

**방법 A: 명령 한 줄 (Windows 10/11)**

명령 프롬프트에서:

```
winget install --id Gyan.FFmpeg -e
```

설치가 끝나면 명령 프롬프트를 **닫았다가 새로 열고** `ffmpeg -version`으로 확인합니다.

**방법 B: 직접 내려받기 (방법 A가 안 될 때)**

1. https://www.gyan.dev/ffmpeg/builds/ 에서 `ffmpeg-release-essentials.zip`을 내려받습니다.
2. 압축을 풉니다.
3. 안의 `bin` 폴더(`ffmpeg.exe`, `ffprobe.exe`가 들어 있음)를 **이 프로젝트 폴더 안에** `ffmpeg\bin` 이름으로 복사합니다.

```
smoking_campaign_15s\
  ffmpeg\
    bin\
      ffmpeg.exe
      ffprobe.exe
```

이 방법은 시스템 설정(PATH)을 바꾸지 않습니다. 스크립트가 이 위치를 먼저 찾아봅니다.

### 1-4. Pillow (그림 라이브러리)

따로 설치하지 않아도 됩니다. `make_video.bat`을 처음 실행할 때 없으면 **"지금 설치할까요? [Y,N]"** 하고 물어봅니다. `Y`를 누를 때만 내 계정에 설치됩니다.

직접 설치하려면: `py -m pip install --user Pillow`

## 2. 영상 만들기

1. 이 폴더에서 **`make_video.bat`을 더블클릭**합니다.
2. 검은 창에 진행 상황이 1단계부터 5단계까지 표시됩니다. (약 2~4분)
3. 끝나면 `output` 폴더가 자동으로 열립니다.

| 파일 | 내용 |
|---|---|
| `output/smoking_campaign_15s.mp4` | 완성된 영상 |
| `output/preview_contact_sheet.jpg` | 장면별 캡처 6장 (빠른 확인용) |

> 설치 상태만 점검하려면 명령 프롬프트에서 이 폴더로 이동한 뒤 `py make_video.py --check`

### 마지막에 나오는 검증 결과

영상이 만들어지면 스크립트가 직접 확인해서 ✓ / ✗로 보여 줍니다.

```
✓ 전체 길이 : 15.000초
✓ 영상 길이 / 프레임 : 15.000초 / 450프레임
✓ 음향 길이 : 15.000초
✓ 해상도 : 1080x1920 (세로 9:16)
✓ 프레임레이트 : 30.00 fps
✓ 영상 코덱 : h264 (yuv420p)
✓ 장면1 자막 (2.6초) : 자막 영역 밝기 차이 28.4
...
```

자막 검사는 자막이 **보여야 하는 순간**과 **없어야 하는 순간**의 화면을 캡처해, 자막 자리의 밝기 차이로 실제로 표시되었는지 판단합니다.

## 3. 연출 노트

| 시간 | 장면 | 연출 |
|---|---|---|
| 0~5초 | 어둠과 담뱃불 | 화면의 유일한 광원은 담뱃불입니다. 담배는 자기 불빛에만 비쳐 불에서 멀어질수록 어둠에 잠깁니다. 연기는 노이즈 질감이 연기 기둥을 따라 흘러 올라가고, 카메라는 불씨를 향해 천천히 다가갑니다. |
| 5~10초 | 꺼짐, 그리고 빛 | 같은 자리의 불씨가 가는 빛의 고리가 되어 조여 들며 꺼집니다(매치 컷). 짧은 정적 뒤, 그 점에서 수평선 같은 빛이 그어지고 위아래로 열리며 어둠을 밀어냅니다. |
| 10~15초 | 아침 | 낮은 해와 가로로 번지는 렌즈 플레어, 렌즈 바로 앞의 흐린 잎, 햇살 속 빛망울. 마지막에 "오늘부터 금연하세요."로 마무리합니다. |

- **색:** 검정과 불씨의 주황 → 중성의 크림색 빛 → 금빛과 녹색 아침
- **자막:** 가는 글씨(맑은 고딕 Semilight)에 자간을 넓혔고, 흐림에서 선명으로 초점이 맞듯 나타납니다. 마지막 문구만 굵은 글씨입니다.
- **사운드(음향 파일이 없을 때 자동 합성):** 낮은 드론과 담배 타는 소리 → 불이 꺼지는 순간 정적 → 빛이 열릴 때 서브 저음 → 따뜻한 화음

## 4. 내레이션과 배경음악 넣기 (선택)

`assets/audio` 폴더에 아래 이름으로 파일을 넣고 다시 실행하면 자동으로 들어갑니다.

| 파일 이름 | 내용 |
|---|---|
| `narration.wav` (또는 .mp3, .m4a) | 내레이션 |
| `music.mp3` (또는 .wav, .m4a) | 배경음악 |

- 배경음악이 15초보다 짧으면 반복하고, 길면 15초에 맞춰 자르고 마지막 1.2초는 페이드아웃합니다.
- 배경음악 파일을 넣으면 자동 합성 사운드 대신 그 음악을 씁니다.
- 내레이션이 나오는 동안 배경음은 **자동으로 작아집니다.**
- 음량과 시작 시간은 `make_video.py` 위쪽의 `MUSIC_VOLUME`, `NARRATION_VOLUME`, `NARRATION_DELAY`에서 바꿀 수 있습니다.
- 소리 없는 영상을 원하면 `SOUND_DESIGN = False`로 바꿉니다.

## 5. 문구나 폰트 바꾸기

`make_video.py` 위쪽의 설정 부분에서 바꿉니다.

```python
SUB1 = ["한 모금의 습관,", "당신의 내일을 바꿉니다."]
SUB2 = ["오늘, 한 번의 선택부터."]
SUB3 = ["금연, 당신의 내일을", "지키는 시작입니다."]
CTA = "오늘부터 금연하세요."
```

폰트는 맑은 고딕(`malgunsl.ttf`, `malgunbd.ttf`)을 먼저 찾습니다. 다른 폰트를 쓰려면 `.ttf` 파일을 `assets/fonts` 폴더에 넣으세요. 이름에 `Light`가 들어간 파일은 가는 글씨로, `Bold`가 들어간 파일은 굵은 글씨로 사용됩니다.

## 6. 문제가 생겼을 때

| 화면에 나오는 내용 | 해결 방법 |
|---|---|
| `Python을 찾지 못했습니다` | 1-2를 따라 설치하세요. **Add python.exe to PATH** 체크를 잊었다면 설치 파일을 다시 실행해 **Modify**로 고치거나, 지우고 다시 설치하세요. |
| `FFmpeg(또는 ffprobe)를 찾지 못했습니다` | 1-3을 따라 설치하세요. 설치 직후에는 창을 **새로 열어야** 인식됩니다. |
| `Pillow ... 설치에 실패` | 인터넷 연결을 확인하고 다시 실행하세요. |
| `한글을 표시할 수 있는 폰트를 찾지 못했습니다` | 한글 `.ttf` 폰트를 `assets/fonts`에 넣으세요. |
| `Permission denied`, `덮어쓸 수 없습니다` | 영상이 동영상 플레이어에서 열려 있습니다. 플레이어를 닫고 다시 실행하세요. |
| `No such filter` | FFmpeg가 오래된 버전입니다. 1-3의 방법으로 최신 버전을 설치하세요. |
| 검증 결과에 ✗가 있음 | 영상은 만들어졌습니다. ✗ 항목의 숫자를 확인하고, 문구를 바꿨다면 자막 위치와 시간을 확인하세요. |

## 7. 폴더 구조

```
smoking_campaign_15s/
├── README.md            이 안내서
├── make_video.bat       더블클릭 실행 파일
├── make_video.py        영상 제작 스크립트
├── assets/
│   ├── audio/           (선택) narration.*, music.*
│   ├── fonts/           (선택) 직접 넣는 한글 폰트
│   └── generated/       실행할 때 자동으로 만들어지는 그래픽 레이어와 자막 이미지
├── build/               중간 작업 파일 (지워도 됨, 다음 실행 때 다시 생김)
└── output/
    ├── smoking_campaign_15s.mp4
    └── preview_contact_sheet.jpg
```

이 프로젝트는 시스템 설정을 바꾸지 않습니다. 파일은 이 폴더 안에만 만들어지고, Pillow도 사용자가 동의할 때만 내 계정에 설치됩니다.
